# 企业指标定义集 —— 设计稿 + 预置内容清单

> 状态：**已实现**（2026-09-07）。下文为设计定稿；实际代码见 `apps/api/src/metric-profile/`、
> `message.service.ts::buildMetricProfileBlock`、`App.tsx` 的 `MetricsAdmin` / 报告选择器。
> 关联需求：报告模式下，在「数据 → 报告」之间插入一层可复用、可多套的「企业指标定义」，
> 由分析师按公司业务预先写好，出报告时勾选一套带进 prompt。分析逻辑仍 100% 委托 huashu-excel。

---

## 一、数据模型

### 1.1 新增 `AiMetricProfile`

```prisma
model AiMetricProfile {
  id            String    @id @default(uuid()) @db.Uuid
  tenantId      String    @map("tenant_id") @db.Uuid
  key           String?   @map("key")            // 预置集的稳定标识（seed 用，如 "central-soe-yylwl"）；自建为 null
  name          String                            // "国资委一利五率对标分析"
  summary       String                            // 一句话，选择器里显示
  category      String                            // 分组：收入/财务/考核/经营/营运/人效/销售/产品/战略
  calibers      Json      @default("[]")          // 口径数组 [{ name, definition }]
  brief         String    @db.Text                // 关注维度 + 分析要求（markdown）
  reportOutline String?   @map("report_outline") @db.Text  // 可选：报告章节大纲
  builtin       Boolean   @default(false)         // 预置集（不可删，可停用；编辑产生副本或就地改由产品决定，见 §4）
  enabled       Boolean   @default(true)
  sortOrder     Int       @default(100) @map("sort_order")
  createdBy     String?   @map("created_by") @db.Uuid
  createdAt     DateTime  @default(now()) @map("created_at")
  updatedAt     DateTime  @updatedAt @map("updated_at")
  deletedAt     DateTime? @map("deleted_at")

  tenant SysTenant @relation(fields: [tenantId], references: [id])

  @@unique([tenantId, key])
  @@index([tenantId])
  @@map("ai_metric_profile")
}
```

- **租户级共享**：一个租户一套库，全租户分析师可选用。
- **`calibers`（口径）半结构化**：`[{ "name": "宽口径", "definition": "..." }]`。这是模型最易算错、价值最高的部分，强制作者写清楚。
- **`brief` 自由 markdown**：关注维度（省内外 / 同比 / 部门 / 产品）、分析要求（强弱项、改进建议、排名）。
- **`reportOutline` 可选**：预置框架自带标准章节结构，喂给 huashu-excel 当报告骨架。作者可留空走 huashu-excel 默认大纲。

### 1.2 `AiSession` 增字段

```prisma
  metricProfileId String? @map("metric_profile_id") @db.Uuid   // 报告任务选定的指标定义集；operate 模式忽略
```

- 建报告任务 / 首条报告消息时落库，任务列表可显示。
- 单条消息可临时覆盖（`POST /sessions/:id/messages` body 加可选 `metricProfileId`），不回写 session。
- `null` = 通用报告（当前行为，不变）。

### 1.3 迁移

`prisma db push`（本项目无 migration 文件，greenfield）。seed 脚本随 `AuthSeedService` 之后执行：`tenantId` 下按 `key` upsert 预置集，已存在则只补不覆盖（保留管理员改动）。

## 三、Prompt 注入（`message.service.ts::buildPrompt`）

`buildPrompt` 增参 `metricProfile?: MetricProfileForPrompt`。仅 `mode === 'report'` 且非空时，在 `REPORT_INSTRUCTIONS` 之后、`FEEDBACK_PROTOCOL` 之前插入：

```
【企业指标定义 · {name}】
本次报告须按下列企业口径与要求展开。口径定义具有最高优先级，若源数据字段与口径不完全对应，按最接近的字段处理并在报告中说明。

■ 口径定义
- {caliber.name}：{caliber.definition}
- ...

■ 关注维度与分析要求
{brief}

■ 报告章节结构（如与 huashu-excel 默认冲突，以此为准）
{reportOutline}      ← reportOutline 为空则整段省略
```

- **预算**：注入块计入 `OPENCODE_HISTORY_MAX_CHARS` 预算核算。单套建议正文上限约 **3000 字**（UI 提示 + 后端 `maxLength` 4000 硬限）。超预算时优先裁历史对话，不裁指标定义块。
- 注入块措辞明确标注为「企业口径」，与「附件内容不可信」条款不冲突（这是系统侧受信配置，非附件夹带）。

### 1. 自研产品收入分析（`revenue-inhouse-product`）

**summary**：按宽口径 / 软服口径 / 窄口径拆解自研产品收入，关注省内外、同比、部门与产品贡献。

**calibers**
- **宽口径**：`<占位：纳入的产品线范围，如"全部自研产品线收入合计">`。一般为最大范围，含硬件、软件、服务、集成等全部自研相关收入。
- **软服口径**：软件产品收入 + 技术服务/运维服务收入，**剔除**硬件、外购集成、转售部分。`<占位：对应源表的哪些产品分类/科目>`
- **窄口径**：`<占位：核心自研产品清单，如仅 A/B/C 三类自主知识产权产品>`，最严格口径，用于考核自主能力。

**brief**
```
关注维度：
- 省内 / 省外：按"归属区域"字段拆分，分别给收入、占比、同比。<占位：区域字段名>
- 同比：与去年同期对比，给增额、增速；有预算/目标值时补充完成率。
- 部门维度：按责任部门汇总三种口径收入，排名，标注完成好/差的部门。
- 产品维度：按产品汇总，排名 Top / Bottom，标注增长最快与下滑最明显的产品。

分析要求：
1. 三种口径的收入规模、结构占比、同比，用表格并列呈现。
2. 省内 vs 省外：结构对比 + 增长贡献分解（谁拉动、谁拖累）。
3. 部门排名与产品排名，各给 Top5 / Bottom5。
4. 基于数据总体诊断强项与弱项（如"软服口径增长健康但窄口径占比偏低，自主产品竞争力不足"）。
5. 给出 3–5 条可落地的改进优化建议，须与数据结论对应。
```

**reportOutline**
```
一、总体情况（三口径收入规模与同比）
二、口径结构分析（宽/软服/窄占比及变化）
三、区域分析（省内外结构与增长贡献）
四、部门贡献与排名
五、产品贡献与排名
六、强弱项诊断
七、改进与优化建议
```

### 2. 财务报表综合分析（`fin-comprehensive`）

**summary**：以杜邦分析为主线，覆盖盈利、营运、偿债、成长四大能力的标准财务比率体系。

**calibers**
- **分析对象**：`<占位：合并报表 / 母公司报表 / 某业务单元>`
- **期间口径**：`<占位：年度 / 季度 / 滚动12个月>`；同比基准为上年同期。

**brief**
```
按杜邦体系展开：ROE = 销售净利率 × 总资产周转率 × 权益乘数，逐层拆解并定位驱动因素。

四大能力核心指标（有数据即算，缺项跳过并说明）：
- 盈利：毛利率、营业利润率、销售净利率、ROE、ROA
- 营运：总资产周转率、应收账款周转率(天)、存货周转率(天)、应付账款周转天数、现金循环周期
- 偿债：资产负债率、流动比率、速动比率、利息保障倍数
- 成长：营业收入增长率、净利润增长率、总资产增长率

分析要求：
1. 杜邦拆解图/表，说明本期 ROE 变化主要由哪个因子驱动。
2. 四大能力逐项给指标值、同比、简评。
3. 横向：如源数据含多主体/多期，做对比。
4. 综合诊断财务健康度，指出主要风险点与优势。
5. 针对性改进建议。
```

**reportOutline**
```
一、财务概览与关键指标一览
二、杜邦分析（ROE 三因子拆解）
三、盈利能力
四、营运能力
五、偿债能力与资本结构
六、成长性
七、财务健康度综合诊断与建议
```

### 3. 盈利能力专项分析（`fin-profitability`）

**summary**：聚焦毛利率、营业利润率、净利率、ROE/ROA 及其结构性驱动。

**calibers**：分析对象、期间口径同 #2。毛利口径 `<占位：是否含运费/折扣>`。

**brief**
```
指标：毛利率、营业利润率、EBITDA 利润率、销售净利率、ROE、ROA、成本费用利润率。
关注维度：同比、环比、按产品线/业务板块拆分毛利率。
分析要求：
1. 各利润率水平与趋势。
2. 毛利率变动归因（价、量、成本、结构）。
3. 三费（销售/管理/研发）占收入比及变化。
4. 盈利质量：经营现金流与净利润的匹配度。
5. 提升盈利的建议。
```

**reportOutline**：一、盈利指标总览 二、毛利率分析与归因 三、期间费用分析 四、盈利质量 五、结论与建议

### 4. 偿债能力与资本结构分析（`fin-solvency`）

**summary**：短期与长期偿债能力、杠杆水平与债务结构。

**calibers**：有息负债口径 `<占位：是否含租赁负债>`；分析对象/期间同 #2。

**brief**
```
指标：流动比率、速动比率、现金比率、资产负债率、有息负债率、权益乘数、利息保障倍数、经营现金流/流动负债。
关注：同比变化、债务期限结构（短期 vs 长期占比）、受限资产。
分析要求：
1. 短期偿债能力评估（结合现金流）。
2. 长期偿债与杠杆合理性，对照国资委"资产负债率保持稳定"的要求。
3. 债务结构与到期分布风险。
4. 优化资本结构建议。
```

### 5. 营运能力（周转效率）分析（`fin-operation`）

**summary**：资产、应收、存货、应付周转效率与现金循环周期。

**calibers**：周转率分母 `<占位：期初期末平均 / 期末值>`；分析对象/期间同 #2。

**brief**
```
指标：总资产周转率、固定资产周转率、应收账款周转天数(DSO)、存货周转天数(DIO)、应付账款周转天数(DPO)、现金循环周期 CCC = DSO + DIO − DPO。
关注：同比、按客户/产品/区域拆分周转。
分析要求：
1. 各周转指标水平与趋势。
2. CCC 分解，指出占用资金的主要环节。
3. 与营收增长匹配度（资产扩张是否带来相应产出）。
4. 释放营运资金的建议。
```

### 6. 成长性分析（`fin-growth`）

**summary**：收入、利润、资产、经营现金流的增长与可持续性。

**brief**
```
指标：营业收入增长率、净利润增长率、扣非净利润增长率、总资产增长率、经营现金流增长率、可持续增长率。
关注：同比、多期 CAGR、增长的结构来源（新业务 vs 存量）。
分析要求：
1. 各增长指标与历史趋势。
2. 增长质量：利润增长是否伴随现金流、是否依赖非经常损益。
3. 增长可持续性（可持续增长率 vs 实际增速）。
4. 增长驱动与瓶颈，建议。
```

### 7. 国资委「一利五率」对标分析（`central-soe-yylwl`）

**summary**：按国资委央国企经营考核体系（一利五率），评估利润总额与五率的达成与优化。

**calibers**
- **一利 —— 利润总额**：利润总额，同时关注净利润、归母净利润"协同增长"。
- **净资产收益率 ROE**：净利润 ÷ 平均净资产。要求同比改善。
- **全员劳动生产率**：全部增加值 ÷ 平均从业人数。`<占位：增加值口径 = 收入法 or 生产法>`。要求同比改善。
- **营业现金比率**：经营活动现金流量净额 ÷ 营业收入。要求同比改善（强调收入含金量）。
- **研发经费投入强度**：研发投入 ÷ 营业收入。要求持续提高。`<占位：研发投入是否含资本化部分>`
- **资产负债率**：负债总额 ÷ 资产总额。要求保持稳定（不显著上升）。

**brief**
```
关注维度：
- 每个指标给：本期值、上年同期值、变动、是否达成"稳定增长/持续优化"的方向要求。
- 有年度目标值时给完成进度。
- 如源数据含多个子企业，逐个对标并汇总排名。

分析要求：
1. "一利五率"一览表（本期 / 同期 / 变动 / 方向达标判断）。
2. 逐指标简析，未达标的说明原因。
3. 价值创造视角：结合 ROE 与营业现金比率判断盈利质量。
4. 短板指标的改进措施。
5. 若为多主体，给整体达标率与红黑榜。
```

**reportOutline**
```
一、"一利五率"总体达成情况
二、利润总额（含净利润、归母净利润协同性）
三、净资产收益率
四、全员劳动生产率
五、营业现金比率
六、研发经费投入强度
七、资产负债率
八、短板诊断与改进措施
```

### 8. 预算执行分析（`budget-execution`）

**summary**：预算数与实际数对比，执行率、偏差率、时间进度匹配度。

**calibers**
- **预算口径**：`<占位：年初预算 / 调整后预算>`
- **执行率**：实际数 ÷ 预算数。
- **偏差率**：(实际 − 预算) ÷ 预算。
- **时间进度**：已过期间 ÷ 预算期间（如年度过 3 个季度 = 75%）。

**brief**
```
关注维度：
- 收入类：执行率越高越好；成本费用类：关注是否超支。
- 按部门 / 项目 / 科目 三个维度分别对比。
- 时间进度匹配：执行率显著低于时间进度 = 进度滞后；显著高 = 可能提前透支或预算偏松。

分析要求：
1. 总体预算执行情况（收入、成本、费用、利润各口径）。
2. 部门 / 项目执行率排名，标红滞后项与超支项。
3. 偏差 Top 项归因。
```
